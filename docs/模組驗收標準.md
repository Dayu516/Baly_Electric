# 模組驗收標準

每個模組在宣告「重構完成 / 可獨立維護」之前，至少要符合以下 6 條。

---

## 1. 單一組裝入口

模組的 service / repository / query service 組裝，只能有 **一個固定入口**。

### 合格
- `application/<module>/__init__.py`
- `application/<module>/builders.py`
- 或其他明確單一入口

### 不合格
- 多個 API 檔各自 `_build_service()`
- route 裡自己拼 repo / query / service

---

## 2. Service 只依賴抽象介面

模組內所有 service：
- 不可直接依賴 `Session`
- 不可直接 import ORM model
- 不可直接寫 raw SQL
- 只能依賴抽象 repository / 明確的 query service

### 合格
- `PurchaseOrderService(repo_a, repo_b, query_service)`

### 不合格
- `PurchaseOrderService(session)`
- service 內直接 `session.query(...)`
- service 內直接 `db.execute("UPDATE ...")`

---

## 3. 讀寫分離固定

### 規則
- **查詢** → `QueryService`
- **寫入** → `Repository`

### 不可混用
- service 有時走 repo、有時自己查 SQL
- query service 順手做 update
- repository 混進報表查詢

---

## 4. 純邏輯有固定落點

所有不依賴 DB 的業務規則，必須集中到固定位置，例如：

- `application/<module>/rules.py`
- `application/<module>/policies/`
- `domain/<module>/policies/`

### 這類都要抽出去
- 狀態推導
- 稅額計算
- 分組邏輯
- 轉單規則
- 驗證規則

### 不合格
- 規則散在各 service private method
- route 裡有商業判斷
- 同類規則一半在 service、一半在 helper

---

## 5. 測試結構固定

每個模組至少要有：

### Unit tests
測純邏輯 / service 規則，不碰 DB
- rules / policies
- service 狀態轉換
- 驗證與計算邏輯

### Integration tests
測真 DB 行為
- repository 寫入
- transaction 邊界
- atomic update
- 真 SQL 查詢
- 跨表一致性

### 原則
- **沒 DB** → unit test
- **有 DB** → integration test

---

## 6. 有一份簡短維護說明

每個模組要有一份短文件，例如：

- `application/<module>/MODULE.md`

內容至少要有：

1. 組裝入口在哪
2. service 清單與職責
3. repository 清單
4. query service 責任
5. 純邏輯位置
6. 哪些邏輯用 unit test 保護
7. 哪些行為必須靠 integration test 驗證

### 目標
之後修改這個模組時，只需要讀：
- 模組自己的程式碼
- 模組自己的測試
- `MODULE.md`
- `CLAUDE.md`
- `Constitution.md`

---

## 驗收口訣

```
1. 只有一個入口組裝
2. service 不直接碰 DB
3. 查詢和寫入分開
4. 純邏輯集中
5. unit / integration 分清楚
6. 模組有自己的說明書
```

---

## 不算完成的情況

出現以下任一項，就不算完成：

- API 檔還在自己組 repo/service
- service 還直接碰 Session / ORM / raw SQL
- 純邏輯散落在 private method
- 測試只有 smoke，沒有模組內 unit test
- 沒有模組自己的維護說明
- 改一條業務規則還要讀很多別的模組

---

## 核心目標

模組完成後，未來修改某一條業務規則時，應只需要閱讀：

1. 該模組程式碼
2. 該模組測試
3. `CLAUDE.md`
4. `Constitution.md`

而不需要再把大量全域上下文帶進來。
